# Security

## What this repo is

A public collection of **text documents only**: a prompt, a guide,
ready-to-send messages, and reference docs. There is no code that runs, no
server, no database, no accounts.

## What must never be committed here

Enforced by `.gitignore`:

- Employee paystubs, W-2s, completed wage claims, witness statements
- Gingr/POS exports, customer invoices, reservation data
- Names or personal information from internal customer records
- Credentials, access tokens, API keys
- Any internal business records

Coworkers work with their **own** documents in their **own** private Muse
chats or on their own devices — never in this repo.

## If private data ever lands in the repo

Remove it immediately, purge it from history if needed, and notify anyone
affected. Do not "fix it later."

## Admin hygiene

- The repo is public so coworkers can open the guide without accounts.
  That's fine — it contains no private data by design. Keep it that way.
- Review every change before pushing. If a change adds anything beyond
  public guidance text, stop and reconsider.
